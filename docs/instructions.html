Topics covered

  • RNA-seq data processing with the nf-core/rnaseq pipeline
  • Mapping of short reads (Bowtie2 for bacteria, STAR for human) and quantification with Salmon
  • Quality control and exploratory data analysis
  • Differential expression analysis (DESeq2)
  • Functional enrichment analysis (ORA & GSEA)

Data

All datasets are bulk RNA-seq. The codes are in the GitHub repository.

  • 🦠 Staphylococcus aureus — biofilm vs planktonic lifestyle over time, strains USA-100 and USA-500, from Tomlinson et al., 2021 (GEO: GSE163153, PRJNA685119). Reference genomes are strain-specific: USA-100 → N315 (GCF_000009645.1); USA-500 → USA300_FPR3757 (GCF_000013465.1), its closest finished relative, as in the paper.
  • 🧑‍🔬 Homo sapiens — primary airway smooth muscle (ASM) cells treated with dexamethasone, paired donor design, from Himes et al., 2014 (GEO: GSE52778, PRJNA229998). Reference genome: GRCh37 (GCF_000001405.13), RefSeq annotation.

Both count matrices were produced with the nf-core/rnaseq pipeline and are provided precomputed in the repository, so the analysis notebooks start from those. For the hands-on pipeline run below we use six sub-sampled S. aureus USA-100 files, so it finishes within class time.
