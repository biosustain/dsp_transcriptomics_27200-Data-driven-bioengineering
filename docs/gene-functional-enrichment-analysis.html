Gene Functional Enrichment Analysis

This report covers functional enrichment analysis of differentially expressed genes from primary human airway smooth muscle (ASM) cells treated with dexamethasone (Himes et al., 2014).

We use GSEA (Gene Set Enrichment Analysis) with fgsea and MSigDB gene sets from msigdbr.

What GSEA does

The differential expression chapter gave you a list of genes. On its own a gene list is hard to interpret: nobody reads 700 gene names and sees biology.

GSEA takes a different angle. Instead of asking “which genes passed a cutoff?”, it ranks every gene you tested, from most up-regulated to most down-regulated, and then asks, for each known set of genes: do the members of this set sit together near one end of that ranking, or are they scattered? A set bunched at the top is activated, one bunched at the bottom is suppressed, and one spread evenly is doing nothing in particular.

Because it uses the whole ranking, GSEA can pick up a pathway where every gene shifts a little but no single gene passes a significance cutoff. That is its advantage, and it is also why no cutoff is applied before running it.

Why these gene sets?

We use the MSigDB Reactome collection: a curated set of detailed human pathways that covers the signalling and immune processes relevant to this experiment. It is a good default for human data, and msigdbr fetches it directly so there are no files to download and keep up to date.
