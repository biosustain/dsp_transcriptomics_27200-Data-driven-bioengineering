27200 Data Driven Bioengineering - Transcriptomics

Quality Control

This report covers the quality control and exploratory analysis of bulk RNA-seq data from Staphylococcus aureus grown as biofilm versus planktonic cultures, from Tomlinson et al., 2021 (GEO: GSE163153, PRJNA685119).

The study profiled five MRSA clonal lineages (USA100–USA500) as biofilm and planktonic cultures at three time points (5 h, 10 h, 24 h). This workshop uses two strains, analysed independently: USA100 (N315 reference) and USA500 (aligned to the USA300 reference). Each strain is a self-contained analysis, following the paper’s own per-strain design.

The contrast of interest is:

  • Biofilm vs planktonic (control), within a single strain and time point

Topics covered

  • Exploratory data analyses
  • Sanity Checks
  • Understanding the time-point structure that the differential expression models build on

Data

  • Reference genome: strain-specific. USA100 → N315 (GCF_000009645.1); USA500 → USA300 (GCF_000013465.1). The USA500 isolate has no finished reference of its own, so USA300 (its closest relative) was used, as in the paper.

  • Input data is the output from the nf-core/rnaseq pipeline salmon.merged.gene.SummarizedExperiment.rds, run with the prokaryotic profile (Bowtie2 + Salmon).

📘 Note: Key points about this dataset:
  • Reads are aligned with a non-splice-aware aligner (Bowtie2), appropriate for bacterial genomes with no introns
  • The pipeline output labels genes by their locus tags (e.g. SA_RS00005 for N315, SAUSA300_RS00010 for USA300). The reference GTF does carry gene symbols for roughly a third of genes (dnaA, arcA, …), and later scripts use them for readability — but the locus tag is the stable identifier throughout
  • Because the two strains use different reference genomes, their gene identifiers are not comparable — the analyses are kept fully separate and are never merged
  • Enrichment analysis (a later script) uses KEGG for S. aureus; g:Profiler does not support this organism

📘 Note on this experiment: The full dataset for each strain contains 32 samples: biofilm and planktonic cultures at 5 h (n = 4 each), 10 h (n = 4 each) and 24 h (n = 8 each). This QC script loads all 32 samples so the PCA can reveal the time-point structure. Script 02 also keeps all time points: it models maturation over time and lifestyle adjusted for time, and uses a single time point (24 h) only for the final hypothesis test — so what you learn here about the time structure directly shapes how you will read those models.

Explanation of the QC analysis 🧾

This document guides you through the standard QC pipeline for bulk RNA-seq data processed with nf-core/rnaseq (Bowtie2 + Salmon, prokaryotic profile). It is structured to be both educational and reproducible.

⭐ One file, two strains. Set the strain variable in the first code chunk to either “USA-100” or “USA-500” and render. Every path, label and output folder below is derived from that one setting, so the same script produces the QC for either strain without further edits.
