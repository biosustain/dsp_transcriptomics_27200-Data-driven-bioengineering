27200 Data Driven Bioengineering - Transcriptomics

Quality Control

This report covers the quality control and exploratory analysis of bulk RNA-seq data from primary human airway smooth muscle (ASM) cells treated with dexamethasone, from Himes et al., 2014 (GEO: GSE52778, PRJNA229998).

The list of contrasts of interest is:

  • Dexamethasone (treatment) vs untreated (control)

Topics covered

  • Exploratory data analyses
  • Sanity Checks

Data

  • Reference genome: human GRCh37 (hg19), as used in the original paper.

  • Input data is the output from the nf-core/rnaseq pipeline salmon.merged.gene.SummarizedExperiment.rds (STAR + Salmon).

📘 Note: Key points about this dataset:
  • Reads are aligned with a splice-aware aligner (STAR), appropriate for spliced human transcripts
  • The reference GTF carries gene symbols, so genes are labelled directly (no ID conversion needed)
  • Enrichment analysis uses g:Profiler with human gene sets (GO, KEGG, Reactome)
  • Cells come from four donors → donor is a candidate confounder in the design (addressed below)

📘 Note on this experiment: The full dataset contains four treatment arms per donor (untreated, albuterol, dexamethasone, albuterol+dexamethasone). Following the study’s primary comparison, this workshop uses only dexamethasone vs untreated (n = 4 per group). Because each donor contributes one treated and one untreated sample, the design is paired.

Explanation of the QC analysis 🧾

This document guides you through the standard QC pipeline for bulk RNA-seq data processed with nf-core/rnaseq STAR + Salmon. It is structured to be both educational and reproducible.
